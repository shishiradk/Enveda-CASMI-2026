## 1. Problem Diagnosis & Root Causes

### A. Why Prior Competition Submissions Failed (`SubmissionStatus.ERROR`, 0 bytes, "A system error")
* **Observations:** Submissions `56881046` and `56883907` for E7 resulted in `SubmissionStatus.ERROR` with `totalBytes: 0` and error message:
  `"A system error. Please try resubmitting to resolve the error and contact Kaggle Support if it persists."`
* **Competition Rule:** In Kaggle Code Competitions, the host evaluation worker re-executes the notebook in an isolated sandbox against the hidden private test dataset.
* **Root Cause:** All attached user datasets (`casmi-e7-c3assets`, `casmi-v2-pubchem`, `casmi-bio-clean`, `casmi-coco-candidates`, etc.) were configured as **Private** (`isPrivate: True`). When Kaggle's evaluation sandbox attempted to mount and read these private datasets, permission was denied. Kaggle masks this permission block with the generic message `"A system error"`.
* **Resolution:** In code competitions, all external training/asset datasets attached to submission kernels **must be publicly accessible**.

### B. Why Kernel v5 Failed at Startup (`KernelWorkerStatus.ERROR`)
* **Observations:** Kernel v5 crashed immediately during container initialization without producing execution output.
* **Root Cause 1 (Deleted Third-Party Wheel):** The dataset `metric/rdkit-2026-3-3-wheel` was deleted (HTTP 404) by its author.
* **Root Cause 2 (Python 3.12 vs 3.13 Mismatch):** When `metric/rdkit-2026-3-3-wheel` was removed, the only remaining RDKit wheel in input was `casmi-rdkit2025-cp313` (built for Python 3.13). However, Kaggle's runtime image runs **Python 3.12 (`cp312`)**. Cell 0's wheel detection:
  ```python
  tag = f"cp{sys.version_info.major}{sys.version_info.minor}"  # 'cp312'
  whl = [w for w in glob.glob("/kaggle/input/**/rdkit-*.whl", recursive=True) if tag in w]
  ```
  found zero matching wheels, causing `whl[0]` to raise an unhandled `IndexError: list index out of range`.
* **Root Cause 3 (Deleted Third-Party Datasets):** `casmi26-fp-models-v2`, `casmi26-ranker-features`, `casmi26-simulated-ranker-rows`, and `coconut-casmi26-candidates` had also been deleted (HTTP 404) by external accounts.
